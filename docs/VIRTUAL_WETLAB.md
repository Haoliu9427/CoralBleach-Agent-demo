# CoralBleach AI 实验台

版本：1.3.0 · 2026-10-18

这是一个可操作、可复现的合成实验环境。它把「设计处理—观察响应—选择模型—运行对照—解释结果」放在同一个页面中。珊瑚形态、剂量范围和响应系数均用于演示，尚未经真实实验校准。

## 操作顺序

1. 打开「Agent 实验室 → 虚拟湿实验」。默认载入环境对照、单独热胁迫、热加硝酸盐、热加铵盐、热加扑草净、复合暴露六组。
2. 点击一个处理组。在左侧点击珊瑚样本或试剂瓶，也可以拖入水槽；只改变当前组。「将当前形态用于所有组」用于统一形态条件。
3. 在下方调整温度、相对光照、时长、示意浓度和独立水槽数。支持 3–8 组，每组 8–30 个独立水槽。浓度字段采用 μmol/L 或 μg/L，页面明确标注单位。
4. 点击「运行虚拟培养」。水槽颜色与时间轴显示合成白化程度；右侧按钮可逐步阅读实验讲解。颜色变浅不表示死亡，Fv/Fm 也是合成代理读数。
5. 选建模方式。未配置密钥时，选「固定顺序基线（无需密钥）」即可完整运行。真实 Agent 模式需要展开页面上方「配置大模型」，填写自己的 ModelScope Token、选择 DeepSeek 或 Qwen，并通过连接检查。
6. 设置 4、8、12、16 或 24 次拟合预算。每个候选、负对照和失败拟合都消耗一次。至少比较两类算法，并为冻结方案完成移除化学变量、训练标签置乱两种对照。
7. 查看实际运行的方案、验证指标、冻结后的测试结果与工具记录。点击已运行的模型卡，可让 Agent 单独解读其结果；右侧导师也可以回答设计问题。LLM 模式完成后自动发起一次结果解读，该请求使用额外模型额度，不计入科学模型拟合次数。
8. 导出 JSON 实验记录或 CSV 水槽数据。冻结前 CSV 只包含训练水槽；冻结后才提供所有分区。修改设计或重新培养会清除本轮结果和导师上下文。

## 32 个方案及插画

32 个方案是 8 类算法与 4 组变量的组合，各有独立 SVG 图标与结果入口。图标解释结构，不代表性能排名。

| 算法 | 首版计算设置 | 图标表达 |
| --- | --- | --- |
| 普通最小二乘 | 含截距；秩不足时拒绝拟合 | 散点与拟合直线 |
| 岭回归 | 标准化输入，λ=2，截距不惩罚 | 系数收缩 |
| Huber 回归 | 12 次迭代加权拟合；阈值自适应；小岭项 0.2 | 大残差降权 |
| 近邻回归 | k=5，标准化欧氏距离，距离加权 | 邻域与距离连线 |
| 回归树 | 深度 3；叶节点至少 3 个训练水槽 | 递归分支 |
| 装袋树集成 | 12 棵自助采样树，深度 4 | 多棵树汇合 |
| 随机森林 | 18 棵树，深度 4，每次分裂抽取约 √p 个特征 | 特征抽样的树群 |
| 梯度提升树 | 24 轮，深度 2，学习率 0.12 | 逐轮修正残差 |

四组输入分别为：温度、相对光照、时长与珊瑚形态；再加入 NO₃⁻ 和 NH₄⁺；再加入扑草净；再加入热×氮、热×扑草净与温度平方项。无变化的列在训练时删除；模型卡和结果记录列出实际使用的变量。

这些算法由无第三方运行依赖的 JavaScript 实现，树模型使用有限阈值网格，Huber 实现包含正则项；不是对某个标准库默认估计器的逐项复刻。SVG 在任何缩放比例下保持清晰，源代码与独立图标随工程交付。

## 合成器假设

以独立水槽为单位生成暴露与响应。每槽 3 个片段共享槽级响应，再加入片段扰动；模型目标是三个片段的白化程度均值。三个虚拟形态 A/B/C 不对应特定真实物种。

令 h=max(0,T−27)×d/14，N、A、P 分别为硝酸盐、铵盐和扑草净的示意浓度，L 为相对光照百分数。槽级潜变量为：

```
z = −3.1 + 0.57h + 0.007(L−100) + 0.16N − 0.07A + 0.3P
    + 0.11hN + 0.13hP + 形态项 + 0.22ε
```

形态项为 A=0.23、B=−0.13、C=0.07。基础白化程度为 100/(1+exp(−z))；每片段加入标准差 3 个百分点的高斯扰动，并截断到 0–100%。温度、光照和添加浓度也存在预设测量扰动。Fv/Fm 用 0.72−0.0046×白化程度再加扰动生成，限制在 0–0.8。

所有系数均为人为设定。特别是氮形态效应方向与形态差异不能被引用为实测发现。五个动画时间点由终点做曲线插值，不是动力学模型。完整实现见 `dist/wetlab-engine.js`。

## 划分、预算与解释

默认每组 12 个独立水槽，按固定种子分配 7 个训练、2 个验证、3 个测试，总计 42/12/18。槽内片段不跨分区。页面观察曲线和分组统计只使用训练分区；标准化和恒定列筛除只在训练数据上拟合。

Agent 能看到设计、训练摘要、候选目录和已执行的验证反馈。它输出受约束的 inspect/evaluate/control/finish 调用；程序检查 ID、参数、预算和冻结条件，实际计算指标。每轮最多发起「预算+5」次规划请求，连续三次非法调用停止；另有轮间四分钟时间检查。服务错误会显示并停止，不会暗中切换为规则结果。

测试只在冻结后计分，不参与本轮选择。重新运行同一设计可以重现相同数据；多次查看后继续调设计属于探索，不能把重复使用的测试集当成最终独立证据。正式评估需要额外封存数据和预先登记的方案。

移除化学变量是消融检查。如果原方案只含热与光照，该操作不会改变输入，结果会提示它不能检验化学增量。标签置乱只打乱训练标签。任何对照结果都描述本合成环境，不构成真实因果证明。

RMSE 和 MAE 的单位为白化程度百分点，R² 是回归指标，不是准确率。训练均值基线采用训练标签均值。此处测试是同一批合成处理条件下的独立水槽测试，不是未见处理、未见珊瑚种或新礁区预测。

## 与全球预警的关系

虚拟实验台用于演示局地复合胁迫假设的操作与模型检验；「时空与化学研究」保留原有时序与区域验证路线。两条路线没有共享真实标定数据，不能把水槽模型的误差换算为全球预警能力。科学问题定义文档中的研究目标、真实证据要求和热应激/白化/死亡边界继续适用。

## 已验证与待验证

本版自动测试覆盖确定性、独立单位、32 个方案、封存测试隔离、预算与冻结条件，以及模拟 LLM 工具循环。浏览器已检查点击、拖放、虚拟培养、固定顺序建模和结果展示。

有效 ModelScope Token 尚未由用户提供，因此没有宣称真实 DeepSeek/Qwen 的本轮端到端生成已通过。首次使用请先检查连接；导师答案仍应结合程序输出核查。Token 仅存于当前页面内存，不进入实验导出。
