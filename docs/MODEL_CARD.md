# 模型卡

用途：研究流程与交互演示；数据：全合成；非现场预警产品。

科学模型：L2正则 Logistic，加性或预设交互项；训练均值/标准差标准化；全批140步、学习率0.2、正则0.015。实现见 dist/engine.js。没有单独校准集，没有统计显著性或因果结论。

评价：AP（按并列概率分组）、Brier、训练发生率参照Brier skill、5箱ECE、Top20%召回。Top-k容量向上取整；并列用稳定索引，常数预测Top-k不具策略含义。阳性/阴性不足10条显示DEFER。重复日期不能视为独立事件。

种子42、H14、B8：启发式AP0.621/局地0.596；Top20%两者均9/23，未增加调查覆盖。20种子平均AP启发式0.542、随机0.585、局地0.417；启发式仅5/20高于随机，17/20高于局地，3次DEFER保留在描述性统计中。不得据单个种子声称优于随机。

真实LLM适配：已实现并通过模拟调用测试；没有远程供应商实测记录或LLM效率成绩。LLM不直接预测标签，不更改评价。

限制：人工生成结构、极少区域、简单模型、缺少真实调查偏差与缺测过程。地图锚点不代表全球覆盖。扩展真实应用前需标签审计、匹配强基线、前向/区域/事件留出、区域校准与块重采样区间。


## v1.1 化学路线

该路线仍使用同一 Logistic 拟合器，以五组变量方案比较化学信息；不是五种独立算法。与空间路线使用不同生成器和版本，旧分数保持原义。完整、缺污染物、仅合并氮三种输入条件对应 20、16、8 个候选。浓度、作用方向和标签为合成假设，不能从演示排序推出生态因果。三种压力测试结果见 results/compound-scenarios.json，协议见 docs/RESEARCH_UPDATE.md。
