# 数据与目标定义

## 两套合成数据分别使用

首页 `dist/data.js`：12个真实地名锚点，DHW、light、mixing、sensitivity、survey、bleaching及outcome全部模拟；字段不是实际地点事实。evidence=A有定量模拟调查，B只有事件报告，U未知；缺失bleaching为null。首页指数是公开情景公式，非训练模型概率。

实验 `engine.generate(seed)`：12个抽象礁区×740天，共8,880行。heat、light、flow、sensitivity、season均为无量纲合成变量；y为生成的二元白化状态。这里heat不是实测DHW；抽象连接不是观测海流。CSV不包含真实地理坐标。生成种子与版本同结果一起保存。

## 时间和分区

预测单位为reef×origin×H，目标为origin+H当日状态。H=7/14/30；输入滞后L=0/7/14/30。预测提前期、输入滞后、生成器隐藏延迟不同。

训练：礁区01–08、origin90–360；验证：09–10、435–525；测试：11–12、600–690；间隔3天。标准化参数只在训练集拟合。区域标签隔离；预测截止前邻区环境可见。反向改变空间连接，错时输入再提前31天，均不读取未来变量。

## 真实接入模板

`data/templates/observations.csv` 是空表头：survey_date是调查日，available_at是首次可用时间；比例定义、分母、方法、深度、类群、证据等级和来源必须保留。没有调查不标作0。预测目标阈值需预先登记；死亡和恢复用单独随访表，不从白化或热应激计算。当前并未实现任意CSV自动导入，模板用于下一阶段适配器开发。

来源候选：NOAA CRW环境产品、GCBD现场白化、HeatCRD恢复资料。尚未接入真实数据。所有接入需核对许可、版本、尺度与发布时效。
